FOREST — REVISED FUTURE PLAN & FEASIBILITY STUDY

Core Focus: Researching argument structure recovery from short political-opinion videos.

System Architecture & Features

  • Domain: Political Opinions & Current Affairs
  • Graph Structure: Root video → Child video replies → Anyone can reply to any node
  • AI Classification: FOR / AGAINST / UNRESOLVED (with community voting for unresolved)
  • Per-Video Scores: Fact Score, Truth Rating, Emotional Appeal Score, Comedy/Satire Score
  • Time Range Traceability: AI cites exact timestamp from which it concluded its result
  • Metadata: AI-generated topic tags + hashtags (or user-provided)

Moderation & Community

  • Community Reporting: Factless, Misleading, Hate Speech, Off-Topic, Deepfake
  • AI-Assisted Report Verification: AI re-checks flagged videos, auto-removes if scores are too low
  • Interest-Based Recommendations: Scores + topics help show users similar debate trees

Evaluation & Tech Stack

  • Testing Plan: 20 self-recorded or sourced short videos, team annotates, then AI classifies, compare F1 scores
  • Tech Stack: Whisper (transcription), Gemini/GPT-4o (classification), Neo4j (graph DB), Spring Boot + React + Flutter

Research Plan Summary

20 Videos → Human Ground Truth → AI Argument Recovery → Timestamp-Grounded Debate Graph → Baseline Comparison → F1/Accuracy Evaluation → Human Usability Test → Full FOREST Prototype
